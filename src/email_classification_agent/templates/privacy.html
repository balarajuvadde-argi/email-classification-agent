Privacy notice

How {{ service_name }} handles Gmail data

Operator: {{ operator_name }} · Effective: {{ privacy_effective_date }} · Notice version: {{ privacy_notice_version }}

Data used

When you run classification, the service reads selected Inbox message headers, text bodies, attachment filenames, and limited prior thread context. It sends bounded content, your classification policy, and allowed label names to {{ ai_provider_name }} solely to return a classification decision.

Gmail actions

The service can create and add user labels. It does not archive, delete, trash, send, forward, or remove labels. Preview mode performs no Gmail writes. In automatic mode, a below-threshold message receives no destination label but does receive a hidden, policy-specific processed marker so it is not repeatedly sent to the model.

Application storage

Your Google refresh token is encrypted with a per-user encryption context. The service stores your policy and bounded run decisions, which can include subjects, senders, reasons, and short evidence snippets; it does not intentionally persist full email bodies or uploaded .eml files. OAuth state expires in minutes, reviewed plans in about {{ plan_minutes }} minutes, browser sessions in about {{ session_hours }} hours, and run details in about {{ run_hours }} hours. Expired records become inaccessible to the application immediately and are physically removed asynchronously by the database service.

Backups

Encrypted DynamoDB point-in-time recovery data may remain recoverable to authorized operators for up to {{ backup_recovery_days }} days. A restore creates a separate protected table; the operator must re-apply previously completed deletion requests before that table can serve traffic. Stack-retained tables and encryption keys require the operator’s documented decommission procedure.

AI service provider

Gmail data is processed only to provide classification. It is not sold, used for advertising, or shared across users. Requests to {{ ai_provider_name }} set store=false, so Responses application state is not retained. Unless the operator has been approved for and configured Modified Abuse Monitoring or Zero Data Retention, OpenAI abuse-monitoring logs may contain prompts and responses for up to 30 days. Review the OpenAI data-controls documentation and contact the operator for the deployment’s current retention configuration.

Your controls

“Disconnect Gmail” first removes the live encrypted connection so new mailbox operations stop, then attempts Google token revocation and deletes version-matched live policy, session, plan, and run records. Short-lived inaccessible records missed by an eventually consistent index expire automatically; encrypted recovery copies follow the backup window above. Contact {{ privacy_contact_email }} for privacy or deletion requests.

Google API Limited Use

{{ service_name }}’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
